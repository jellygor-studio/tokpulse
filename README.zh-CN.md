# TokPulse（中文说明）

面向 Antigravity `v2.34.0+` 的官方原生 **MCP App** 实时速度、缓存省钱计算、项目账单与会话效率诊断看板。

零调试启动器、零渲染进程注入、不修改宿主文件，Antigravity 自动升级后持续稳定运行。

## 核心能力

1. **全局 / 自动跟随 / 单会话三种监控模式**：默认监控整个 Antigravity 的实时速度、缓存命中率与累计消耗；也可一键切到「自动跟随最新活跃会话」或查看指定对话。子代理碎片自动计入总账但隐藏于列表外，保持清爽。
2. **实时速度卡片 + 像素小狮子动画**：查看最新速度（`tok/s`）、均值、单轮耗时、峰值与当前模型；右上角支持波形折线与像素小狮子双模式切换。
3. **多语言自动适配**：自动跟随 Antigravity 宿主与系统语言（内置简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch 8 种语言，其他语种自动回退英文）。
4. **Pro 核心功能**：
   - 按公开 API 参考费率实时核算等价花费与**缓存累计节省金额**；
   - 按工作区 / 项目自动拆分成本账单；
   - 0–100 会话效率评分、**前缀缓存断崖检测**（精准定位掉缓存的步骤与额外损失成本）与 `/compact` 时机提醒；
   - 一键导出 **CSV 账单** 与 **Markdown 周期报告**（支持在侧边栏直接预览）。

## 安装与本地构建

```bash
npm install
npm run typecheck
npm test
npm run install:plugin   # 本机开发自用版（含 Pro 预览）
npm run build:release    # 构建对外正式发布包 release/tokpulse/
```
